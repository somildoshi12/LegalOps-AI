# LegalOps AI Deployment Hub: Feature Guide

This document provides a detailed breakdown of all the key features built into the **LegalOps AI Deployment Hub** platform, detailing how each component operates and addresses operational bottlenecks.

---

## 🚀 Key Features

### 1. 💼 Law Firm Onboarding Wizard
The onboarding wizard guides users through configuring custom parameters for their firm. This configures the system rules dynamically:
- **Practice Area Mapping**: Adapts AI behaviors to specific legal areas (e.g., Personal Injury).
- **Workflow Automation Target**: Toggle between drafting a full settlement letter or only performing fact extraction/summarization.
- **Preferred Tone Registry**: Dictates prompt parameters for document writing (e.g., *Professional & Assertive* for personal injury cases vs. *Technical & Legalistic*).
- **Review Policy**: Sets validation steps (e.g., whether drafts require double partner sign-offs or allow paralegal pre-screening).

---

### 2. 📝 Client Intake Portal
A intake interface designed to ingest unstructured client data:
- **Rich Document Uploader**: Ingests files like medical invoices, police accident logs, or customer intake briefs. Supported file extensions: `.txt`, `.pdf`, and `.docx`.
- **Text Narrative Area**: Copy-paste text narratives for immediate intake without local file uploads.
- **Recruiter Demo Datasets**: Two pre-populated case profiles (Robert Vance - MVA, and Linda Martinez - Slip & Fall) designed for immediate testing without preparing documents.
- **Real-Time Step Checklist**: Submitting an intake triggers a loading timeline showing the backend executing tasks: parsing files, running LLM extractions, routing paralegal tasks, and quality evaluations.

---

### 3. 📊 Interactive Case Dashboard
The centralized case workspace provides summary statistics and filtering capabilities:
- **Metric Cards**: Tracks total matters, cases awaiting review, generated drafts, and the average quality score of all AI outputs.
- **State Filtering**: Sort cases by workflow status (`New Intake`, `AI Reviewed`, `Draft Generated`, `Closed`) or matter types (e.g., `Motor Vehicle Accident`, `Premises Liability`).
- **Interactive Cards**: High-fidelity cards featuring matter details, priority flags, received dates, and the AI overall quality score.

---

### 4. 📁 Case Detail Workspace
A split-screen detail interface for checking and completing cases:
- **Extracted Structured Facts Panel**: Renders clean, color-coded monospace JSON fields containing parties, dates, injuries, medical bills, risk flags, and missing information.
- **Operational Task Checklist**: Displays tasks generated by the AI for attorneys and paralegals. Checking items marks them completed in the SQLite database in real-time.
- **Dual-Tab Output Panel**: Allows seamless toggling between the Markdown Case Summary and the generated Settlement Demand Letter Draft.
- **LLM-As-Judge Scorecard**: Renders metric scores for *Completeness*, *Grounding*, and *Safety* alongside final validation scores.
- **Attorney Feedback Loop**: Form allowing practitioners to rate the draft (`Accurate`, `Needs minor edits`, etc.), classify errors (`Incorrect facts`, `Tone too weak`), and submit corrections.
- **AI Agent Rerun Trigger**: Triggers a manual execution of the multi-agent orchestrator directly from the workspace view.

---

### 5. 🛠 Production Debug Console
A tracer interface providing complete transparency over the agent pipeline:
- **Run Directory**: View list of all agent runs chronologically.
- **Trace Timeline**: Shows every pipeline step (`extractCaseFacts`, `classifyMatter`, `generateCaseSummary`, `generateTasks`, `generateDemandLetter`, `runEvaluations`), with step latency, tokens consumed, input summary, and output summary.
- **System Diagnostics**: Tracks total token counts, latency benchmarks, and cost estimates. Displays full error messages for failed pipeline steps.

---

### 6. 📈 Feedback Analytics & Automated Roadmap
A dashboard translating attorney feedback into actionable software tasks:
- **Rating Charts**: Displays percentage bars of draft quality ratings.
- **Issue Flag Trends**: Compiles occurrences of failure states (e.g., hallucinated facts or tone issues).
- **Automated Roadmap Generator**: Synthesizes issue trends into technical recommendations (e.g., recommending factual cross-checking or prompting adjustments if particular flags exceed thresholds).

---

## 🛠 Tech Stack Details
- **Frontend**: React, TypeScript, Tailwind CSS v4, Lucide-React.
- **Backend**: Node.js, Express, Prisma, SQLite, Multer, PDF-Parse, Mammoth.
- **LLM Engine**: Multi-provider wrapper supporting OpenAI, Anthropic, Ollama, and a context-aware mock engine.
